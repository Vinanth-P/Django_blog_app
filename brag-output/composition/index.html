Getting Started with Django Framework

Django is a high-level Python web framework that encourages rapid development and clean, pragmatic design. Built by experienced developers, it takes care of much of the hassle of web development, so you can focus on writing your app without reinventing the wheel.

It includes a full object-relational mapper (ORM), user authentication, admin panel, dynamic templating, form validation, and URL routing out of the box.
